# OrangeHRM Testing & Automation Project

## 📌 Project Overview

This project contains **manual and automated testing artifacts** for the OrangeHRM system.
The repository includes requirements analysis, test planning, test cases, bug reports, API testing, and automation testing using Selenium.

The goal of the project is to ensure the **quality, functionality, and reliability** of the OrangeHRM system through structured testing practices.

---

# 📂 Project Structure

### 1️⃣ Requirements Before Static Testing

Contains the initial system requirements gathered before performing static testing.

### 2️⃣ Requirements After Static Testing

Updated and refined requirements after applying static testing techniques such as requirement reviews and corrections.

### 3️⃣ Test Plans

Includes the test planning documentation such as:

* Testing scope
* Testing strategy
* Resources
* Schedule
* Risk management

### 4️⃣ Test Cases

Manual test cases written to verify system functionality and validate requirements.

### 5️⃣ API Test Cases

Test cases designed to validate system APIs including:

* Request validation
* Response validation
* Status code verification
* Data integrity

### 6️⃣ Bug Reports

Contains documented defects discovered during testing including:

* Bug description
* Steps to reproduce
* Expected result
* Actual result
* Severity and priority

### 7️⃣ Automation Test Cases

Automated test scripts developed to test system features using **Selenium WebDriver**.

### 8️⃣ Closure Reports

Final testing reports summarizing:

* Testing results
* Defects found
* Test coverage
* Final evaluation of system quality

### ⚙️ Automation

Contains the automation framework implementation including:

* Selenium test scripts
* Page Object Model structure
* TestNG configuration
* Test execution setup

# 🚀 How to Run Automation Tests

1. Clone the repository

```
git clone <repository-url>
```

2. Open the project in **IntelliJ IDEA**

3. Install dependencies (if using Maven)

```
mvn clean install
```

4. Run the TestNG test suite

```
testng.xml
```
